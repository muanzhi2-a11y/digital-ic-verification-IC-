- Task 输入参数的声明、方向和位置传参；调用实参按 task 声明顺序对应。
- `!==` 可将 X/Z 状态纳入不等比较；`||` 表达逻辑或；`$fatal` 用于失败终止；`$display` 用于打印信息。
- `initial`、`begin/end/endtask`、`$dumpfile`、`$dumpvars`、`$finish` 的基本结构和用途。
- 当前 RTL 使用连续赋值且没有显式建模门延迟。仿真中输出在输入变化后经事件调度更新；零显式延迟不代表真实芯片不存在传播延迟。
- Verilator 的 `--lint-only`、`--timing`、`-Wall`、`--top-module`、`--binary`、`--trace`、`--Mdir` 等选项已在本次工程中接触。
