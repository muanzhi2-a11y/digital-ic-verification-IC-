### 1. RTL 设计

用户独立编写 `alu.v`，实现一个 4 bit ALU。

模块接口：

|---|---:|---|
| A | 4 bit | input |
| B | 4 bit | input |

运算控制编码：

| ALU_Sel | 运算 | 功能 |
|---|---|---|
| 000 | ADD | 加法 |
| 001 | SUB | 减法 |

主要 RTL 表达式：

```verilog
{Carry, Result} = {1'b0, A} + {1'b0, B};

{Borrow, Result} = {1'b0, A} - {1'b0, B};

Result = A & B;

Result = A | B;

Result = A ^ B;
```

在 `always @(*)` 开头设置 Result、Carry、Borrow 的默认值，避免组合逻辑锁存器推断。

- 4 bit 无符号数扩展到 5 bit 后进行加减法。
- 补码表示负数的基本原理。
- 负数补码与求一个数相反数之间的关系。
- 使用 5 bit 减法结果的最高位判断本设计中的无符号借位。
- Carry 和 Borrow 的区别。
- `case`、`default` 的使用。
- 组合逻辑默认赋值与锁存器推断风险。
